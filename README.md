# Тренер полезных привычек

Простое веб-приложение без зависимостей: откройте `index.html` в браузере.

- Добавляйте привычки, которые хотите выполнять каждый день.
- Каждый день отмечайте выполненные (кружок слева). Последние 7 дней внизу карточки — чтобы исправить пропущенные отметки.
- Для каждой привычки показывается **текущая серия** и **рекорд** (максимальная серия) в днях. Текущая серия не сбрасывается, пока сегодняшний день ещё не закончился.

Данные хранятся в `localStorage` браузера.
