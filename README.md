# YouBoost — трекер полезных привычек

Веб-приложение без сборки: HTML, CSS и JavaScript-модули. Работает на GitHub Pages:
https://shusandrik23.github.io/Poleznieprivichki/

## Что умеет

- **Привычки.** Свои или из готового списка по категориям. Каждый день отмечаете, что сделали; последние 7 дней можно исправить.
- **Серии.** Для каждой привычки — текущая серия и рекорд в днях. Текущая серия не сбрасывается, пока день не закончился.
- **Цели.** Сколько дней подряд выполнять привычку (7, 21, 30, 66, 100 или своё число), с полосой прогресса.
- **Цитата дня.** При первом запуске за день — цитата на весь экран (Аристотель, Драйден и др.). Список — в `js/quotes.js`.
- **Пазл и заморозки.** За каждый день, когда человек открыл приложение, — кусочек пазла 🧩. 7 кусочков = 1 заморозка ❄️: если вчера пропущен день в привычке с целью, заморозка спасает серию (замороженный день не засчитывается, но серия не прерывается). В вызовах и турнирах заморозки не действуют.
- **Факт дня.** «Если каждый день делать 5 отжиманий, за год наберётся 1 825…» — и кнопка, чтобы сразу добавить эту привычку. Факты — в `js/facts.js`.
- **Аккаунт** (вход через Google). Привычки синхронизируются между устройствами. Без входа всё работает и хранится только на устройстве.
- **Ник и приватность.** Каждый выбирает ник. Галочка «показывать друзьям настоящее имя» — иначе даже друзья видят только ник.
- **Друзья.** Заявки по нику, у каждого друга — сравнение серий по общим привычкам. В карточке привычки видно серии друзей по ней же.
- **Соперники для вас.** На вкладке «Вызовы» сами появляются случайные люди с такими же привычками, которые недавно заходили, — вызов в одно касание. На вкладке «Друзья» — полный поиск. Новые пользователи видны в подборе по умолчанию (только ник и серии); отключается в настройках.
- **Поделиться серией.** Кнопка в карточке привычки: картинка «🔥 12 дней подряд» для сторис и постов плюс текст со ссылкой-вызовом «кто продержится 21 день?».
- **Турниры.** Каждый понедельник автоматически стартует турнир недели для всех (привычки по кругу), плюс особые турниры к датам. Записаться можно заранее или в первые два дня. Таблица лидеров и ваше место. В турнире засчитываются только отметки, сделанные в тот же день (время ставит сервер — задним числом не отметить). По желанию можно добавить фото-подтверждение: фото видят все участники в ленте турнира, и если 3 участника отметят «Не похоже на правду», этот день не засчитывается.
- **Приглашения по ссылке.** Кнопки WhatsApp / «Поделиться» / «Скопировать ссылку»: можно позвать друга, которого ещё нет в приложении, или сразу бросить ему вызов. Открыв ссылку и войдя, он становится другом, а вызов начинается.
- **Вызовы.** Кто дольше продержится с привычкой N дней подряд. Пропуск дня — выбываете. Вызов можно бросить и по своей, придуманной привычке — её нет в общем списке, она добавится обоим.
- **Удаление аккаунта** прямо в приложении (обязательно для App Store).

Кто что видит (гарантируют правила в `firestore.rules`):

| Данные | Кто видит |
|---|---|
| Ник | Все вошедшие пользователи |
| Серии по привычкам | Друзья; остальные — если включено «показывать меня» (по умолчанию включено) |
| Участие в турнире | Все вошедшие (ник и прогресс в таблице лидеров) |
| Настоящее имя | Только друзья и только с галочкой |
| Отметки по дням, настройки | Только владелец |

## Бесплатный тариф

Настраивается в `js/plans.js`:

- **Привычки, вызовы и турниры** — без ограничений.
- **Цели:** 3 активные, **+1 за каждого друга, который зарегистрировался по вашей ссылке** (засчитываются только новые пользователи).
- Подписка YouBoost Plus (без ограничений) появится вместе с оплатой через Google Play. Отключить все ограничения — `limitsEnabled: false`.

## Языки

Русский и английский. Язык выбирается по языку телефона или браузера, переключатель RU / EN — в шапке.

- Тексты интерфейса — `js/locales/ru.js` и `js/locales/en.js` (одинаковые ключи).
- Каталог привычек — `js/catalog.js`: у каждой привычки есть код, поэтому «Read for 20 minutes» и «Читать 20 минут» — одна и та же привычка. Люди с разными языками видят друг друга в подборе соперников, у друзей и в турнирах, а название каждый видит на своём языке.
- Факты, цитаты и турниры — на обоих языках в `js/facts.js`, `js/quotes.js`, `js/tournaments.js`.

Чтобы добавить язык: скопировать `js/locales/en.js`, перевести, подключить в `js/i18n.js` и добавить переводы в каталог, факты, цитаты и турниры.

## Как добавить турнир

Каждый понедельник турнир недели стартует сам (привычки — список `WEEKLY_HABITS` в `js/tournaments.js`). Особый турнир к дате — объект в списке `SPECIAL` там же:

```js
{ id: 'summer2027', habit: 'steps', start: '2027-06-01', days: 30,
  title: { ru: 'Летний марафон', en: 'Summer marathon' },
  text: { ru: '30 дней прогулок вместе со всеми.', en: '30 days of walking together with everyone.' } },
```

`habit` — код привычки из `js/catalog.js`. Анонс появится у всех за 14 дней до старта.

## Подключение сервера (Firebase)

Пока в `firebase-config.js` стоит `null`, вкладки «Друзья» и «Вызовы» показывают «скоро». Чтобы включить их:

1. Откройте https://console.firebase.google.com → **Create a project** (Google Analytics можно выключить).
2. **Build → Authentication → Get started → Sign-in method → Google → Enable → Save.**
3. **Authentication → Settings → Authorized domains → Add domain:** `shusandrik23.github.io`.
4. **Build → Firestore Database → Create database.** Режим — *production*, регион — например `eur3 (Europe)`.
5. **Firestore Database → Rules:** замените текст содержимым файла `firestore.rules` → **Publish**.
6. **Project settings (шестерёнка) → General → Your apps → значок `</>` (Web)** → зарегистрируйте приложение → скопируйте объект `firebaseConfig`.
7. Вставьте его в `firebase-config.js` вместо `null`. Эти значения не секретные, их можно хранить в открытом репозитории.

## Android-приложение (Capacitor)

Проект Android уже лежит в папке `android/`: название YouBoost, пакет `com.youboost.app`, своя иконка и заставка.

**Готовый APK без всякой установки.** При каждом обновлении ветки GitHub сам собирает приложение: вкладка **Actions** → последний запуск **Android APK** → внизу **Artifacts** → `youboost-debug`. Внутри — `app-debug.apk`: перекиньте на телефон и установите (Android попросит разрешить установку из этого источника).

**Сборка на своём компьютере** (нужны Node.js 22 и Android Studio):

```bash
npm install
npm run sync          # собирает веб-часть в www/ и переносит в android/
npm run open:android  # открывает проект в Android Studio → Run
```

После любых изменений в `index.html` или `js/` — снова `npm run sync`.

Что уже работает в приложении по-нативному: системное меню «Поделиться» (в том числе картинкой серии), WhatsApp, копирование, кнопка «Назад». Ссылки-приглашения ведут на сайт https://shusandrik23.github.io/Poleznieprivichki/.

**Вход через Google в приложении** настроен: Android-приложение `com.youboost.app` зарегистрировано в Firebase, файл `android/app/google-services.json` лежит в проекте, тестовые сборки подписываются постоянным ключом `android/app/debug.keystore` (SHA-1 `4D:39:77:3A:C4:6E:AF:54:87:85:F5:32:26:5B:25:7C:AA:E8:72:11` добавлен в Firebase). Для релизной сборки в Google Play нужно будет добавить в Firebase и SHA-1 ключа Google Play (Play Console → App integrity).

## Путь в Google Play

1. Аккаунт разработчика Google Play (разовый взнос $25).
2. Ключ подписи для релиза и сборка `.aab` (`./gradlew bundleRelease`).
3. Страница с политикой конфиденциальности и форма Data safety в консоли Google Play. Удаление аккаунта в приложении уже есть — Google Play его требует.
4. Позже: **Health Connect** — автоматически отмечать привычки по шагам, сну и тренировкам.

Вход через Apple не нужен, пока нет версии для iPhone. Кнопка уже готова: `appleSignInEnabled` в `firebase-config.js`.

**Друзья из Facebook.** Meta отдаёт список друзей только тех, кто тоже вошёл в приложение через Facebook, и требует проверки приложения в Meta. Пока ту же задачу решают ссылки-приглашения: их можно отправить и в Messenger.
