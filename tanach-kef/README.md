# מַסָּע בַּתַּנַ״ךְ — прототип

Тренажёр в духе Duolingo для 2–4 классов: ребёнок учится понимать оригинальный текст Танаха через «перевод» библейских форм на современный иврит.

Это кликабельный веб-прототип для проверки идеи. Сборка не нужна: HTML, CSS и JS. Чтобы запустить локально:

```
cd tanach-kef && python3 -m http.server 8000
# открыть http://localhost:8000
```

## Что есть

- **Карта:** Книги → Истории → 4 урока + «אוֹצַר הַחָכְמָה» (контрольная игра по истории). Уроки открываются по порядку.
- **Урок** из 4 этапов: הַסִּפּוּר → מִלִּים מֵהַתַּנַ״ךְ (3 карточки) → הַפָּסוּק שֶׁלָּנוּ (оригинальный стих; слова урока подсвечены, у трудных слов есть подсказки) → תִּרְגּוּל.
- **Задания:** מִלּוֹן תַּנַ״ךְ (найти пару), הַשְׁלֵם אֶת הַפָּסוּק (собрать стих из плиток, иногда с лишней плиткой), מִי אָמַר?, בַּלַּשׁ הַתַּנַ״ךְ и вопросы на значение слов.
- **Мягкие ошибки:** при неверном ответе вопрос уходит в конец круга, урок всегда можно закончить.
- **Мотивация:** свитки XP (10 за урок, +5 без ошибок, 20 за сундук), огонёк серии дней, маскот גִּילִי (свиток), который подбадривает и не ругает.
- **הַמִּלּוֹן שֶׁלִּי:** изученные слова попадают в словарь; повторение по системе Лейтнера (через 1, 2, 4, 8, 16, 32 дня); на карте появляется карточка «пора повторить».
- **Озвучка:** если у урока есть готовый аудиофайл (поле `audio` у стиха), играет он; иначе — системный синтез речи `he-IL`.
- Весь текст с полным никудом. Шрифты: Frank Ruhl Libre (пасуким) и Rubik (интерфейс). Светлая и тёмная тема.

Готовый контент: «בְּרִיאַת הָעוֹלָם» и «נֹחַ וְהַתֵּבָה» (8 уроков, 24 слова, 14 стихов). Остальные истории на карте отмечены «בְּקָרוֹב».

## Контент

Всё лежит в `content/course.json`. Чтобы добавить историю, нужно добавить объект в `stories` нужной книги. Код при этом не меняется.

Разметка слов в стихе:

- `{בָּרָא|bara}` — слово из урока (ссылка на `id` в `words`);
- `{תְהוֹם|=מַיִם עֲמֻקִּים}` — разовая подсказка прямо в тексте.

Типы заданий: `match` (пары строятся из слов урока), `order` (`text`, по желанию `extra`), `who` (`quote`, `answer`, `options` — id персонажей), `choice` (`kind`: `meaning` | `detective`, `q`, `options`, `answer`, по желанию `explain`).

## Чего не хватает до MVP по ТЗ

- Приложение на Flutter (iOS/Android/Web). Формат JSON подходит для него без изменений.
- Заранее записанная озвучка с правильным ударением (мильэль/мильра) и кэш для работы офлайн.
- Проверка текстов и огласовок методистом/учителем Танаха.
- Остальные истории Берешит, Шмот, Судей и Царей.
