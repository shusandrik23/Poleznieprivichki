# מַסָּע בַּתַּנַ״ךְ — прототип

Тренажёр в духе Duolingo для 2–4 классов: ребёнок учится понимать оригинальный текст Танаха через «перевод» библейских форм на современный иврит.

Это кликабельный веб-прототип для проверки идеи. Сборка не нужна: HTML, CSS и JS. Чтобы запустить локально:

```
cd tanach-kef && python3 -m http.server 8000
# открыть http://localhost:8000
```

## Что есть

- **Карта:** Книги → Истории → 4 урока + «אוֹצַר הַחָכְמָה» (контрольная игра по истории). Уроки открываются по порядку.
- **Урок** из 4 этапов: הַסִּפּוּר → מִלִּים מֵהַתַּנַ״ךְ (3 карточки) → הַפָּסוּק שֶׁלָּנוּ (оригинальный стих; слова урока подсвечены, у трудных слов есть подсказки) → תִּרְגּוּל.
- **Задания:** מִלּוֹן תַּנַ״ךְ (найти пару), הַשְׁלֵם אֶת הַפָּסוּק (собрать стих из плиток, иногда с лишней плиткой), מִי אָמַר?, בַּלַּשׁ הַתַּנַ״ךְ и вопросы на значение слов.
- **Мягкие ошибки:** при неверном ответе вопрос уходит в конец круга, урок всегда можно закончить.
- **Мотивация:** свитки XP (10 за урок, +5 без ошибок, 20 за сундук), огонёк серии дней, маскот גִּילִי (свиток), который подбадривает и не ругает.
- **הַמִּלּוֹן שֶׁלִּי:** изученные слова попадают в словарь; повторение по системе Лейтнера (через 1, 2, 4, 8, 16, 32 дня); на карте появляется карточка «пора повторить».
- **Озвучка:** если у урока есть готовый аудиофайл (поле `audio` у стиха), играет он; иначе — системный синтез речи `he-IL`.
- Весь текст с полным никудом. Шрифты: Frank Ruhl Libre (пасуким) и Rubik (интерфейс). Светлая и тёмная тема.

Программа охватывает начальную школу целиком, примерно по программе государственных школ (ממלכתי): 5 «книг», по одной на класс, 37 историй, 148 уроков, 444 слова. Каждый класс открывается отдельно, внутри класса уроки идут по порядку.

## Русский режим

Кнопка **RU** в шапке включает помощь для русскоговорящих детей. Иврит остаётся основным языком: в школе Танах учат на иврите. Русский текст появляется под ним:

- перевод вводной истории, значений слов, вопросов, вариантов ответов и пояснений;
- перевод стиха по кнопке «Показать перевод», чтобы ребёнок сначала попробовал понять сам;
- кнопки и инструкции на русском;
- экран **«Имена»** (👥): ивритское имя, как его произносят в школе, и как его называют по-русски (נֹחַ — Ноах — Ной). В переводах имена записаны как «Ноах (Ной)».

Русские тексты лежат в `content-src/ru/` (по файлу на класс, ключи — id уроков, порядок элементов как в ивритском файле). Если перевод чего-то не хватает, сборка падает с ошибкой.

## Тексты для проверки

`review/tanach-kef-texts.docx` — все тексты курса на иврите и русском, урок за уроком, с отмеченными верными ответами. Пересобрать после правок: `python3 tools/export-review.py` (нужен `pip install python-docx`).

## Android-приложение (Capacitor)

Внутри APK работает та же веб-версия, обёрнутая в Capacitor: ID `com.tanachkef.app`, название «מסע בתנ״ך». С YouBoost оно не связано, у него своя папка `android/` и своя сборка.

- **Скачать APK:** GitHub → Actions → «Tanach Kef APK» → последний запуск → Artifacts → `tanach-kef-debug`. Сборка запускается сама при каждом изменении в папке `tanach-kef/`.
- **Работает без интернета:** уроки, шрифты и код лежат внутри приложения.
- **Озвучка** идёт через системный синтез речи Android (плагин `@capacitor-community/text-to-speech`): встроенный браузер Android сам говорить не умеет. Нужен голос на иврите: Настройки → Синтез речи → Google → скачать «עברית».
- **Кнопка «Назад»** возвращает на карту, а на карте сворачивает приложение.

Собрать самому (нужны Node 22, JDK 21 и Android Studio или Android SDK):

```
cd tanach-kef
npm install
npm run apk                 # APK: android/app/build/outputs/apk/debug/app-debug.apk
npm run open:android        # или открыть проект в Android Studio
```

Другие команды: `npm run fonts` копирует шрифты из npm в `fonts/`, `node tools/make-icons.cjs` перерисовывает иконки и сплэш из `icon.svg`.

Перед публикацией в Google Play: ID приложения потом нельзя будет сменить, а для релизной сборки нужен отдельный ключ подписи, которого нет в репозитории.

## Контент

Уроки пишутся в `content-src/` (один файл на класс, персонажи в `_meta.json`). Скрипт `tools/build-course.mjs` собирает из них `content/course.json`, который читает приложение.

Текст стихов вручную не набирается: скрипт берёт его из Ленинградского кодекса (WLC, пакет `morphhb` от OpenScriptures, общественное достояние). Огласовки сохраняются, знаки кантилляции убираются, вместо ктива подставляется кри, Имя пишется как ה׳.

```
npm pack morphhb@2.0.2 && tar -xzf morphhb-2.0.2.tgz        # один раз, в любую папку
node tools/build-course.mjs <путь>/package/wlc               # собрать course.json
node tools/build-course.mjs <путь>/package/wlc --show Gen.1.1 # показать стих с номерами слов
```

Формат урока (сокращённо):

```json
{ "id": "noah-3", "title": "הַיּוֹנָה", "icon": "🕊️",
  "story": ["…предложения на современном иврите…"],
  "v": ["Gen.8.8", "Gen.8.11:1-10"],
  "w": [["וישלח", "שָׁלַח"], ["הקלו", "הַאִם יָרְדוּ"]],
  "g": [["מאתו", "מֵאֶצְלוֹ"]],
  "order": "Gen.8.8:1-6", "extra": ["הָעֹרֵב"],
  "who": ["Gen.22.7:12-17", "yitzhak", ["avraham", "eved"]],
  "q": [["d", "вопрос?", ["верный ответ", "неверный", "неверный"], "пояснение"]] }
```

- `v`: ссылки на стихи; после двоеточия можно указать диапазон слов.
- `w`: слова урока (без огласовок, как в стихе) и их перевод. Если слова нет в стихах урока, сборка падает с ошибкой.
- `g`: подсказки к другим трудным словам.
- `order`: фрагмент для задания «собери пасук»; `who`: цитата и кто её сказал.
- `q`: вопросы. `m` — на значение слова, `d` — «детектив». Первый вариант верный, в приложении варианты перемешиваются.

## Чего не хватает до MVP по ТЗ

- iOS-версия (нужен Mac с Xcode) и релизная сборка для Google Play.
- Возможный переход на Flutter. Формат JSON подходит для него без изменений.
- Заранее записанная озвучка с правильным ударением (мильэль/мильра) и кэш для работы офлайн.
- Проверка текстов и огласовок методистом/учителем Танаха.
- Сверка с официальной программой Министерства образования (она отличается в государственных и государственно-религиозных школах).
