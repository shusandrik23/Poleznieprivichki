# Таблетка от всего

PWA с 11 интерактивными практиками для проработки эмоций, страхов, зависимостей и целей. Устанавливается на телефон или открывается в браузере, работает без интернета, все записи хранятся только на устройстве.

Сборка не нужна: HTML + CSS + JS-модули. Локально: `python3 -m http.server 8000` в корне репозитория → http://localhost:8000

Публикация: Settings → Pages → Deploy from branch → `main`, папка `/ (root)`.

## Возможности

- **SOS** на главном экране: голос сразу ведёт по шагам практики «SOS»; рядом — вариант без звука, крупными карточками.
- **Мастер подбора** — 10 жизненных запросов → подходящие практики.
- **Три режима:**
  - 🎧 *Ведёт приложение* — озвучка браузером, весь экран — зона касания «дальше», в циклах экран делится на «Есть ещё» (верх) и «Больше ничего нет» (низ) с вибрацией, таймеры со звуковым сигналом, экран не гаснет. Голосовые команды — по желанию.
  - 👥 *В паре* — экран суфлёра: крупный текст, подсказки ведущему, счёт кругов, замеры 1–10, «Поменяться ролями».
  - 📝 *Соло* — карточки и поля для записей.
- **Холст** (`js/canvas.js`) вместо листа А4: «Я», «Я1», «Я2», блокады с процентами, корень всех блокад, колодец; на каждом шаге — только нужные маркеры; переворот на 180°; карта 7 уровней; сохранение картинкой в галерею.
- **Линия времени** (`js/timeline.js`): остановки с шагом 5 лет до раннего детства и обратно.
- **Сжигание** (`js/burn.js`): анимация огня и пепла для письма и старых убеждений.
- **«Перепрошивка»** (`js/course.js`, `js/ppp.js`): дневник из 15 пунктов, шаблоны «Питание / Алкоголь / Курение / Другое», оценка дня, счётчик формулы самонастроя 20–50, напоминание и файл .ics для календаря телефона.
- **Календарь закрепления** (`js/beliefs.js`): 14 утренних дней с новым убеждением и счётчиком повторений.
- **Таблица чувств** (`js/feelings.js`): 5 цветовых групп плюс сопутствующие мысли и состояния; кнопка 💗 на любом шаге.
- **Журнал**, резервная копия в JSON, полное удаление данных.
- **Приватность и офлайн**: всё в `localStorage`, сетевых запросов нет; service worker (`sw.js`) кэширует приложение.

## Как править тексты

- Сценарии всех практик — в `js/techniques.js`. Общая цепочка выгрузки (слова → чувство → каким я становлюсь → куда тянет) — функция `vent()`.
- Шаг — объект вида `ask('Текст вопроса', 'ключ')`; типы шагов описаны в начале файла. Подстановки `{person}`, `{topic}`, `{goal}` берутся из ответов.
- Дневник «Перепрошивки» — в `js/ppp.js`.
- После правок увеличьте `CACHE` в `sw.js` (`tabletka-v3` …), чтобы установленные приложения подтянули новую версию.

Практики основаны на подходе ТВП (Трансцендентная Ведическая Психология); тексты пересказаны своими словами. Приложение не заменяет психолога или врача.
