# Внутренний компас — PWA для проработки эмоций

Отдельное веб-приложение в папке `compass/`. Сборка не нужна (HTML + CSS + JS-модули). После публикации на GitHub Pages:
https://shusandrik23.github.io/Poleznieprivichki/compass/

Локально: `cd compass && python3 -m http.server 8000` → http://localhost:8000

## Что есть

- **SOS (Скорая помощь)** на главном экране — голос сразу ведёт по 6 шагам; рядом ссылка «без звука» на крупные карточки.
- **Мастер подбора** — 9 запросов (зависимости, авторитеты, травмы, детские обиды, предназначение, цели…) → подходящие техники.
- **11 техник** в трёх режимах по матрице (`modes` в `js/techniques.js`):
  - 🎧 *Ведёт приложение* — озвучка браузером (ru-RU), весь экран — зона касания «дальше», в циклах экран делится на «Есть ещё эмоция» (верх) / «Больше ничего нет» (низ) с вибрацией, таймеры со звуковым сигналом, экран не гаснет. Голосовые команды — по желанию в настройках.
  - 👥 *В паре* — экран суфлёра: крупный текст «Прочитайте партнёру», подсказки «Для ведущего», счёт кругов, замеры 1–10, в конце «Поменяться ролями».
  - 📝 *Соло* — карточки и поля для записей. У «Силы авторитета» и «Глубокой перезагрузки» соло открывается после 3 прохождений с гидом или партнёром.
- **Холст** (`js/canvas.js`): «Я», «Я1», «Я2», «Цель», «Блокады» с ползунком 1–100 %, «КВБ», «Колодец», 6 сфер; переворот на 180°; карта 7 уровней рода; сохранение картинкой (на телефоне — «Поделиться → Сохранить в галерею»).
- **Линия времени** (`js/timeline.js`): по возрасту строит остановки с шагом 5 лет до 3–5 лет (34 → 29 → … → 4) и обратно.
- **Сжигание** (`js/burn.js`): анимация огня и пепла для письма и старых убеждений из Колодца.
- **Курс «ППП»** (`js/course.js`, `js/ppp.js`): 14 вечеров по 15 пунктам оригинала, шаблоны «Питание / Алкоголь / Курение / Другое», оценка дня 1–10, счётчик формулы самонастроя 20–50, напоминание (уведомление, пока приложение открыто, + файл .ics для календаря телефона — работает без сервера).
- **Календарь закрепления** (`js/beliefs.js`): 14 утренних дней с новым убеждением и счётчиком повторений; убеждение добавляется в один клик в конце глубокой практики.
- **Таблица чувств** (`js/feelings.js`): таблица из «Техник ТВП» — 5 цветовых кластеров плюс «мысли и состояния», поиск; кнопка 💗 на любом шаге.
- **Журнал** всех прохождений (до/после, ответы, карта), резервная копия в JSON, полное удаление.
- **Приватность и офлайн**: всё в `localStorage` браузера, сетевых запросов нет; service worker (`sw.js`) кэширует приложение.

## Источник и тексты техник

Сценарии составлены по документу «Техники ТВП» (Трансцендентная Ведическая Психология, Владимир Древс): шаги, вопросы и формулировки идут в порядке оригинала, адаптированы только под экран, голос и холст. Таблица чувств (вместе с «Мыслями и состояниями») — из того же документа.

- Все сценарии — в `js/techniques.js`. Общая цепочка «достань и покажи» (слова → эмоция → какой я → что хочется сделать: убежать, спрятаться, замереть, исчезнуть, напасть) — функция `vent()`.
- Дневник ППП (15 пунктов) — в `js/ppp.js`. Шаблон «Питание» — дословно из документа; «Алкоголь», «Курение» и «Другая привычка» составлены по его образцу («если привычка другая — измени форму под себя»).
- Шаг — объект вида `ask('Текст вопроса', 'ключ')`; типы шагов описаны в начале файла. Подстановки `{person}`, `{topic}`, `{goal}` берутся из ответов.
- После правок увеличьте `CACHE` в `sw.js` (`kompas-v3` …), чтобы установленные приложения подтянули новую версию.
