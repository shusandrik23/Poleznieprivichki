# Мой список

Простое Android-приложение: три списка — **Книги**, **Подкасты**, **Дела** — с галочкой у каждого пункта.

- У пункта есть название, ссылка (открывается по нажатию) и короткое описание.
- «+» — добавить пункт; нажатие на пункт — изменить, перенести в другой список или удалить.
- Меню ⋮ → **Загрузить из файла** — добавить сразу много пунктов из `.txt` (пример: [`primer.txt`](primer.txt)).
- Меню ⋮ → **Сохранить в файл** — резервная копия в том же формате.
- Можно «Поделиться» ссылкой из браузера / YouTube / приложения подкастов прямо в «Мой список».
- Всё хранится только на телефоне, интернет и аккаунты не нужны.

## Формат файла

```
# Книги
Название | ссылка | описание
[x] Уже прочитанная книга

# Подкасты
Арзамас | https://arzamas.academy

# Дела
Записаться к врачу
```

Ссылка и описание необязательны. Строки без заголовка попадают в открытую вкладку. Повторы не добавляются.

## Как получить APK

Сборку делает GitHub Actions при каждом изменении папки `spisok/`:
вкладка **Actions** → **Spisok APK** → последний запуск → **Artifacts** → `moy-spisok-apk` (zip с `app-debug.apk`).
Скачайте на телефон, распакуйте и установите (разрешите установку из неизвестных источников).

Локально: открыть папку `spisok/` в Android Studio или `cd spisok && ./gradlew assembleDebug`.
