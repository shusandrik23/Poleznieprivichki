# Мой список

Простое Android-приложение со списками — сначала **Книги**, **Подкасты**, **Дела**, плюс любые свои категории — с галочкой у каждого пункта.

- У пункта есть название, ссылка (открывается по нажатию) и короткое описание.
- Меню ⋮ → **Новая категория** — добавить свою вкладку (например, «Фильмы»). Долгое нажатие на вкладку —
  переименовать, сдвинуть левее/правее или удалить.
- «+» — добавить пункт; нажатие на пункт — изменить, перенести в другой список или удалить.
- Меню ⋮ → **Загрузить из файла** — добавить сразу много пунктов из `.txt` (пример: [`primer.txt`](primer.txt)).
- Меню ⋮ → **Сохранить в файл** — резервная копия в том же формате.
- Можно «Поделиться» ссылкой из браузера / YouTube / приложения подкастов прямо в «Мой список».
- Свой **Telegram-бот** (без сервера): пишете боту — пункты появляются в приложении.
- Всё хранится только на телефоне, аккаунты не нужны (интернет нужен только для бота).

## Формат файла

```
# Книги
Название | ссылка | описание
[x] Уже прочитанная книга

# Подкасты
Арзамас | https://arzamas.academy

# Дела
Записаться к врачу
```

Ссылка и описание необязательны. Незнакомый заголовок (`# Фильмы`) создаёт новую категорию. Строки без заголовка попадают в открытую вкладку. Повторы не добавляются.

## Telegram-бот

1. В Telegram откройте @BotFather → `/newbot` → придумайте имя → скопируйте токен.
2. В приложении: меню ⋮ → **Telegram-бот** → вставьте токен → «Сохранить».
3. Откройте чат с ботом, нажмите «Старт», вернитесь в приложение — бот привяжется к вам
   (сообщения от других людей он игнорирует).

Пишите боту по одному пункту в строке:

```
книга Мастер и Маргарита
подкаст Арзамас | https://arzamas.academy | про историю
дело Записаться к врачу
```

Первое слово строки может выбрать любую категорию: `фильм Дюна` попадёт в «Фильмы». Без такого слова пункт попадает в «Дела», а ссылки на подкасты и книжные сайты — в свои списки.
Пересланный пост становится одним пунктом. Можно прислать боту `.txt` файл в формате выше.

Сервера нет: приложение забирает сообщения у бота, когда вы его открываете, и тогда же бот отвечает «✅».
Telegram хранит непрочитанные сообщения боту **24 часа** — открывайте приложение хотя бы раз в сутки.

## Как получить APK

Сборку делает GitHub Actions при каждом изменении папки `spisok/`:
вкладка **Actions** → **Spisok APK** → последний запуск → **Artifacts** → `moy-spisok-apk` (zip с `app-debug.apk`).
Скачайте на телефон, распакуйте и установите (разрешите установку из неизвестных источников).

Локально: открыть папку `spisok/` в Android Studio или `cd spisok && ./gradlew assembleDebug`.
