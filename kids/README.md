# YouBoost Kids — полезные привычки для детей

Отдельное приложение для семей с детьми 6–14 лет. Лежит в папке `kids/` того же репозитория и работает на том же Firebase-проекте, что и YouBoost.
Сайт (после публикации ветки на GitHub Pages): https://shusandrik23.github.io/Poleznieprivichki/kids/

## Как это устроено

**Родитель** задаёт привычки и награды и подтверждает важные дела. **Ребёнок** отмечает дела, копит звёзды, растит питомца и собирает наклейки.

Пользоваться можно двумя способами:

1. **На одном телефоне.** Родитель открывает «Режим ребёнка». Выйти из него можно только по PIN-коду родителя.
2. **На телефоне ребёнка.** Родитель входит через Google, нажимает «Дети» → «Подключить телефон ребёнка» и получает код из 6 символов. На телефоне ребёнка нужно выбрать «Это телефон ребёнка» и ввести код. Ребёнку не нужен ни аккаунт, ни почта: телефон входит анонимно и видит только свою семью.

3. **Взрослый в обычном YouBoost.** Во вкладке «Дети» взрослого YouBoost можно создать семью, добавить детей, получить код для телефона ребёнка, посылать задачи и принимать вызовы. Ставить YouBoost Kids себе взрослому не нужно. Семья общая: если мама работает в YouBoost, а папа в YouBoost Kids, оба видят одно и то же.

4. **Ребёнок начинает сам.** На первом экране есть кнопка «🚀 Я ребёнок — начну сам». Ребёнок получает случайный ник («Весёлый Енот 42», можно перебросить 🎲), выбирает возраст и аватар. Сразу работают дела, звёзды, питомец и наклейки, а свои дела ребёнок добавляет сам (✏️ «Мои дела»). Всё хранится **только на телефоне**, запросов к серверу нет. Награды, друзья и вызовы закрыты, вместо них кнопка «👨‍👩‍👧 Позвать»: она отправляет маме или папе сообщение с инструкцией. Родитель добавляет ребёнка (в YouBoost во вкладке «Дети» или в YouBoost Kids) и присылает ссылку. Ребёнок открывает её, и телефон подключается к семье: звёзды, питомец и отметки переезжают в семью. Если у карточки ребёнка ещё нет привычек, переезжают и они. Имя остаётся то, которое дал родитель. Подключение родителем и есть его согласие, поэтому только после него данные ребёнка попадают на сервер и открываются друзья.

Без аккаунта всё хранится только на устройстве. Аккаунт Google можно подключить позже («Ещё» → «Подключить аккаунт Google»): семья перенесётся в облако. Второй родитель подключается кодом: «Ещё» → «Пригласить второго родителя».

## Что умеет

- **Привычки.** Готовый каталог из 40 детских привычек в 7 категориях (`js/catalog.js`) или свои. У каждой привычки есть значок, число звёзд (1–5) и дни недели. Например, «Уроки» только по будням, а «Полить цветы» по средам и субботам. Можно включить «Нужно подтверждение родителя»: звёзды начислятся, когда родитель нажмёт «Засчитать». При первой настройке приложение предлагает набор привычек по возрасту.
- **Звёзды и награды.** Звёзды даются за дела, бонусы и семейные вызовы. Родитель задаёт награды и их цену в звёздах (в приложении есть идеи наград). Ребёнок нажимает «Хочу!», родитель получает запрос и выдаёт награду или отказывает. Если отказал, звёзды возвращаются.
- **Питомец.** Ребёнок выбирает один из 10 зверьков. Сначала это яйцо, оно вылупляется после первых 5 звёзд. Дальше у питомца 9 уровней с украшениями (бантик, шарф, очки, шляпа, корона). Настроение зависит от сегодняшних дел: питомец танцует, когда всё сделано, и скучает, если ничего не отмечено.
- **Наклейки.** 21 достижение: серии 3/7/14/30/100 дней, «идеальные дни», звёзды, награды, победы в вызовах. Новая наклейка появляется на весь экран с конфетти.
- **Семейные вызовы.** Родитель выбирает привычку, срок (3–30 дней), бонус и участников: детей и родителей. У вызова есть таблица результатов и победитель. Все, кто прошёл все дни, получают бонусные звёзды.
- **Задачи от взрослых.** Из YouBoost взрослый посылает задачу на сегодня, на завтра или на каждый день. У ребёнка она отмечена «📬 от мамы». Разовые задачи исчезают из списка через две недели, а заработанные за них звёзды остаются.
- **Вызов взрослому.** На вкладке «Вызовы» у ребёнка есть кнопка «⚔️ Бросить вызов взрослому»: выбрать маму или папу, привычку и срок. Взрослый принимает вызов в YouBoost (или в YouBoost Kids), и вызов стартует на следующий день.
- **Приглашение ссылкой.** Родитель отправляет ребёнку ссылку из YouBoost («Дети» → «Пригласить в YouBoost Kids») или из YouBoost Kids («Подключить телефон ребёнка» → «Поделиться»): через WhatsApp, SMS или любое приложение. Ребёнок открывает ссылку (`…/kids/?join=КОД`), и YouBoost Kids подключается к семье сам, без ввода кода.
- **Друзья.** Вкладка «Друзья» у ребёнка. Друга **из контактов телефона** ребёнок добавляет сам, без одобрения: выбирает контакт, и приглашение уходит по SMS или WhatsApp. Друг **по коду или ссылке** появляется только после того, как его разрешат родители обоих детей (в YouBoost во вкладке «Дети» или в YouBoost Kids на вкладке «Сегодня»). Поиска людей нет. У друга видно имя, аватар и питомца. Родитель видит всех друзей ребёнка и может удалить любого.
- **Вызовы друзьям.** Кнопка «⚔️ Вызов» у друга: привычка и срок. Друг принимает вызов, и он начинается сегодня. Отметка такой же привычки в своих делах засчитывается в вызове сама.
- **Серии** 🔥 считаются только по дням из расписания привычки. Пока сегодняшнее дело не отмечено, серия не обрывается. Вчерашнее дело ребёнок может отметить сам.
- **Родителю:** вкладка «Сегодня» с подтверждениями и запросами наград, история отметок за 7 дней (можно отметить за ребёнка), бонусные звёзды, PIN-код, звуки, языки RU/EN, удаление ребёнка или всей семьи.
- **Безопасность детей:** нет рекламы, покупок, аналитики, чатов и поиска людей. Политика конфиденциальности: `privacy.html`.

## Данные и правила доступа

Firestore (раздел «YouBoost Kids» в общем `firestore.rules`):

| Путь | Что там | Кто может менять |
|---|---|---|
| `kidsFamilies/{fid}` | название, награды, вызовы, родители | родители |
| `kidsFamilies/{fid}/kids/{id}` | привычки, отметки, подтверждения, запросы, питомец | родители: всё; телефон ребёнка: только `marks`, `requests`, `chMarks`, `pet`, `proposals` (вызовы взрослым), а `habits` — только в пустой список (перенос из самостоятельного режима) |
| `kidsFamilies/{fid}/members/{uid}` | подключённые родители и телефоны | создаются только по действующему коду |
| `kidsCodes/{код}` | код подключения (24 часа) | родители |
| `kidsUsers/{uid}` | в какой семье пользователь | сам пользователь |
| `kidsFriendInvites/{код}` | приглашение в друзья (7 дней), способ: `contact` или `code` | ребёнок или его родитель |
| `kidsFriendships/{A_B}` | дружба двух детей: карточки, одобрения, вызовы, отметки | каждая сторона — только своё; одобряет только родитель |

Звёзды нигде не хранятся готовым числом: они каждый раз считаются из отметок, подтверждений, бонусов и вызовов (`js/logic.js`). Поэтому ребёнок не может «накрутить» баланс, а правила проверяли на эмуляторе: ребёнок не может сам подтвердить дело, начислить бонус, выдать награду, поменять привычки или стать родителем, а посторонний не видит семью.

## Что включить в Firebase (один раз)

1. **Authentication → Sign-in method → Anonymous → Enable.** Без этого не подключится телефон ребёнка.
2. Опубликовать обновлённые правила (команда из основного README):
   `npx -y firebase-tools@15.34.2 deploy --only firestore:rules --project poleznie-privichki`

Домен `shusandrik23.github.io` уже есть в Authorized domains, поэтому вход через Google на сайте работает сразу.

## Android-приложение

Папка `kids/android/`: название YouBoost Kids, пакет `com.youboost.kids`, своя иконка и заставка. GitHub собирает APK при каждом обновлении ветки: **Actions** → **Android APK** → Artifacts → `youboost-kids-debug`.

Сборка на своём компьютере:

```bash
cd kids
npm install
npm run sync          # веб-часть → www/ → android/
npm run open:android  # Android Studio → Run
```

**Вход через Google в Android-версии** пока выключен, потому что нужен файл настроек Firebase именно для пакета `com.youboost.kids`. Без него в приложении работают режим без аккаунта и подключение телефона ребёнка по коду, а облачная семья родителя доступна на сайте. Чтобы включить вход:

1. Firebase → Project settings → **Add app → Android**, пакет `com.youboost.kids`, SHA-1 `4D:39:77:3A:C4:6E:AF:54:87:85:F5:32:26:5B:25:7C:AA:E8:72:11` (тот же отладочный ключ, что у YouBoost).
2. Скачать `google-services.json` в `kids/android/app/`.
3. `cd kids && npm install @capacitor-firebase/authentication@8.5.2` и добавить в `capacitor.config.json` блок `plugins.FirebaseAuthentication` как в основном приложении, а в `android/variables.gradle` — `rgcfaIncludeGoogle = true`.

Кнопка «Войти через Google» появится в приложении сама.

**Ссылки-приглашения** (`?join=` и `?friend=`) открывают сайт YouBoost Kids. Чтобы они сразу открывали установленное Android-приложение, нужны App Links: файл `assetlinks.json` на домене. На `shusandrik23.github.io` его можно положить только в корневой репозиторий `shusandrik23.github.io`, поэтому сейчас это не настроено. Сайт при этом работает полностью, и его можно добавить на главный экран.

## Проверка на эмуляторе Firebase

```bash
npx firebase-tools emulators:start --only auth,firestore --project demo-habits
python3 -m http.server 8765      # из корня репозитория
```

Откройте http://127.0.0.1:8765/kids/?emulator
