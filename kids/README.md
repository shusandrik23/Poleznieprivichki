# YouBoost Kids — полезные привычки для детей

Отдельное приложение для семей с детьми 6–14 лет. Лежит в папке `kids/` того же репозитория и работает на том же Firebase-проекте, что и YouBoost.
Сайт (после публикации ветки на GitHub Pages): https://shusandrik23.github.io/Poleznieprivichki/kids/

## Как это устроено

**YouBoost Kids — только для детей.** Родитель всё делает во взрослом приложении YouBoost, во вкладке «Дети»: создаёт семью, добавляет детей, задаёт привычки и награды, подтверждает дела, запросы наград и новых друзей, создаёт семейные вызовы, начисляет бонусы и приглашает второго родителя. Ставить YouBoost Kids себе родителю не нужно.

Ребёнок попадает в YouBoost Kids двумя путями:

1. **По ссылке от родителя.** В YouBoost: «Дети» → «📲 Пригласить в YouBoost Kids» → «Отправить ссылку» или WhatsApp. Ребёнок открывает ссылку (`…/kids/?join=КОД`), и YouBoost Kids подключается к семье сам. Можно и ввести код из 6 символов («Мне прислали ссылку или код от родителя»). Ребёнку не нужен ни аккаунт, ни почта: телефон входит анонимно и видит только свою семью и своих друзей.
2. **Сам, без родителя.** Кнопка «🚀 Я ребёнок — начну сам»: случайный ник («Весёлый Енот 42», можно перебросить 🎲), возраст и аватар. Сразу работают дела, звёзды, питомец и наклейки, свои дела ребёнок добавляет сам (✏️ «Мои дела»). Всё хранится **только на телефоне**, запросов к серверу нет. Награды, друзья и вызовы закрыты, вместо них кнопка «👨‍👩‍👧 Позвать»: она отправляет маме или папе сообщение с инструкцией для YouBoost. Когда родитель добавит ребёнка и пришлёт ссылку, звёзды, питомец и отметки переедут в семью, а если у карточки ребёнка ещё нет привычек, переедут и они. Подключение родителем и есть его согласие, поэтому только после него данные ребёнка попадают на сервер и открываются друзья.

Если на телефоне осталась старая настройка «Я родитель» из ранней версии, YouBoost Kids показывает экран «Родители — в YouBoost» со ссылкой на взрослое приложение.

## Что умеет

- **Привычки.** Готовый каталог из 40 детских привычек в 7 категориях (`js/catalog.js`) или свои. У каждой привычки есть значок, число звёзд (1–5) и дни недели. Например, «Уроки» только по будням, а «Полить цветы» по средам и субботам. Можно включить «Звёзды — после моего подтверждения»: звёзды начислятся, когда родитель засчитает дело в YouBoost. При добавлении ребёнка ему сразу ставится набор привычек по возрасту. Привычками управляет родитель в YouBoost («Дети» → «⚙️ Настроить»).
- **Звёзды и награды.** Звёзды даются за дела, бонусы и семейные вызовы. Родитель задаёт награды и их цену в звёздах (в приложении есть идеи наград). Ребёнок нажимает «Хочу!», родитель получает запрос и выдаёт награду или отказывает. Если отказал, звёзды возвращаются.
- **Питомец.** Ребёнок выбирает один из 10 зверьков. Сначала это яйцо, оно вылупляется после первых 5 звёзд. Дальше у питомца 9 уровней с украшениями (бантик, шарф, очки, шляпа, корона). Настроение зависит от сегодняшних дел: питомец танцует, когда всё сделано, и скучает, если ничего не отмечено.
- **Наклейки.** 21 достижение: серии 3/7/14/30/100 дней, «идеальные дни», звёзды, награды, победы в вызовах. Новая наклейка появляется на весь экран с конфетти.
- **Семейные вызовы.** Родитель выбирает привычку, срок (3–30 дней), бонус и участников: детей и родителей. У вызова есть таблица результатов и победитель. Все, кто прошёл все дни, получают бонусные звёзды.
- **Задачи от взрослых.** Из YouBoost взрослый посылает задачу на сегодня, на завтра или на каждый день. У ребёнка она отмечена «📬 от мамы». Разовые задачи исчезают из списка через две недели, а заработанные за них звёзды остаются.
- **Вызов взрослому.** На вкладке «Вызовы» у ребёнка есть кнопка «⚔️ Бросить вызов взрослому»: выбрать маму или папу, привычку и срок. Взрослый принимает вызов в YouBoost, и вызов стартует на следующий день.
- **Друзья.** Вкладка «Друзья» у ребёнка. Друга **из контактов телефона** ребёнок добавляет сам, без одобрения: выбирает контакт, и приглашение уходит по SMS или WhatsApp. Друг **по коду или ссылке** появляется только после того, как его разрешат родители обоих детей (в YouBoost во вкладке «Дети»). Поиска людей нет. У друга видно имя, аватар и питомца. Родитель видит всех друзей ребёнка и может удалить любого.
- **Вызовы друзьям.** Кнопка «⚔️ Вызов» у друга: привычка и срок. Друг принимает вызов, и он начинается сегодня. Отметка такой же привычки в своих делах засчитывается в вызове сама.
- **Серии** 🔥 считаются только по дням из расписания привычки. Пока сегодняшнее дело не отмечено, серия не обрывается. Вчерашнее дело ребёнок может отметить сам.
- **Родителю (в YouBoost, вкладка «Дети»):** подтверждения и запросы наград, привычки, профиль ребёнка, история отметок за 7 дней (можно отметить за ребёнка), бонусные звёзды, награды, семейные вызовы, подключённые телефоны, второй родитель, удаление ребёнка или всей семьи.
- **Безопасность детей:** нет рекламы, покупок, аналитики, чатов и поиска людей. Политика конфиденциальности: `privacy.html`.

## Данные и правила доступа

Firestore (раздел «YouBoost Kids» в общем `firestore.rules`):

| Путь | Что там | Кто может менять |
|---|---|---|
| `kidsFamilies/{fid}` | название, награды, вызовы, родители | родители |
| `kidsFamilies/{fid}/kids/{id}` | привычки, отметки, подтверждения, запросы, питомец | родители: всё; телефон ребёнка: только `marks`, `requests`, `chMarks`, `pet`, `proposals` (вызовы взрослым), а `habits` — только в пустой список (перенос из самостоятельного режима) |
| `kidsFamilies/{fid}/members/{uid}` | подключённые родители и телефоны | создаются только по действующему коду |
| `kidsCodes/{код}` | код подключения (24 часа) | родители |
| `kidsUsers/{uid}` | в какой семье пользователь | сам пользователь |
| `kidsFriendInvites/{код}` | приглашение в друзья (7 дней), способ: `contact` или `code` | ребёнок или его родитель |
| `kidsFriendships/{A_B}` | дружба двух детей: карточки, одобрения, вызовы, отметки | каждая сторона — только своё; одобряет только родитель |

Звёзды нигде не хранятся готовым числом: они каждый раз считаются из отметок, подтверждений, бонусов и вызовов (`js/logic.js`). Поэтому ребёнок не может «накрутить» баланс, а правила проверяли на эмуляторе: ребёнок не может сам подтвердить дело, начислить бонус, выдать награду, поменять привычки или стать родителем, а посторонний не видит семью.

## Что включить в Firebase (один раз)

1. **Authentication → Sign-in method → Anonymous → Enable.** Без этого не подключится телефон ребёнка.
2. Опубликовать обновлённые правила (команда из основного README):
   `npx -y firebase-tools@15.34.2 deploy --only firestore:rules --project poleznie-privichki`

Домен `shusandrik23.github.io` уже есть в Authorized domains, поэтому вход через Google на сайте работает сразу.

## Android-приложение

Папка `kids/android/`: название YouBoost Kids, пакет `com.youboost.kids`, своя иконка и заставка. GitHub собирает APK при каждом обновлении ветки: **Actions** → **Android APK** → Artifacts → `youboost-kids-debug`.

Сборка на своём компьютере:

```bash
cd kids
npm install
npm run sync          # веб-часть → www/ → android/
npm run open:android  # Android Studio → Run
```

Входа через Google в YouBoost Kids нет и не нужно: дети подключаются анонимно по ссылке или коду, а родители пользуются YouBoost.

**Ссылки-приглашения** (`?join=` и `?friend=`) открывают сайт YouBoost Kids. Чтобы они сразу открывали установленное Android-приложение, нужны App Links: файл `assetlinks.json` на домене. На `shusandrik23.github.io` его можно положить только в корневой репозиторий `shusandrik23.github.io`, поэтому сейчас это не настроено. Сайт при этом работает полностью, и его можно добавить на главный экран.

## Проверка на эмуляторе Firebase

```bash
npx firebase-tools emulators:start --only auth,firestore --project demo-habits
python3 -m http.server 8765      # из корня репозитория
```

Откройте http://127.0.0.1:8765/kids/?emulator
