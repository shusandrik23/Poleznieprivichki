# Говорун — тренажёр ораторского искусства

Android-приложение в стиле Duolingo: истории великих ораторов, голосовые тренировки и конструктор речи. Интерфейс написан на HTML/CSS/JS без сборщика и упакован в нативное Android-приложение через Capacitor, так же как YouBoost Kids.

**Где взять APK:** вкладка Actions на GitHub → последний запуск «Android APK» → Artifacts → `govorun-debug`.

## Что внутри

- **Шапка.** Огонёк 🔥 (дни подряд), очки харизмы 💎 со званием (Новичок → Рассказчик → Оратор → Трибун → Златоуст), 5 сердечек ❤️ и аватар, который открывает профиль.
- **Истории.** Карта-«змейка» модуля «Магия первого впечатления». В модуле 4 кейса: Стив Джобс (правило трёх), Уинстон Черчилль (контраст), Авраам Линкольн (самоирония), Билл Гейтс (крючок внимания). Каждый кейс состоит из шести шагов:
  1. история из жизни;
  2. рентген речи: фразы выступления подчёркнуты, нажатие открывает нижнюю карточку с объяснением приёма;
  3. антипример: та же мысль, сказанная скучно, и разбор, что в ней не так;
  4. тест на 3 варианта: за ошибку сгорает сердечко, Попугай объясняет;
  5. сборка фразы из плиток;
  6. голосовой челлендж на 20 секунд с кнопкой «Я сейчас не могу говорить».

  В конце экран «Урок пройден» с конфетти и очками харизмы, а на карте открывается следующий кейс.
- **Тренажёр.** Лифтовая презентация: случайная тема и 45 секунд. Импровизация: 60 секунд, каждые 10 секунд новое слово, которое нужно вплести в рассказ. После записи приложение показывает темп (слов в минуту), слова-паразиты подсвечены в расшифровке, а Попугай даёт отзыв. За каждую речь +1 ❤️.
- **Конструктор.** Мастер из 4 шагов «Проблема → Интрига → Решение → Призыв» с подсказками и примерами. В конце готовая шпаргалка с кнопками «Скопировать текст» (системный буфер обмена) и «Поделиться» (меню Android).
- **Профиль.** Статистика, колода приёмов (карточки открываются после уроков и переворачиваются), достижения, звук и вибрация, сброс прогресса.
- **Сохранение.** Весь прогресс хранится только на телефоне (localStorage WebView) и не пропадает при закрытии приложения.
- **Звуки и вибрация.** Звуки генерируются через Web Audio, аудиофайлов нет. Вибрация идёт через плагин Haptics.

## Распознавание речи

На телефоне работает встроенный распознаватель Android (`SpeechRecognizer`, язык ru-RU) через плагин `@capacitor-community/speech-recognition`. Разрешение на микрофон система спрашивает при первой записи. Распознаватель сам останавливается после паузы, поэтому `js/speech.js` перезапускает его, пока идёт таймер, и склеивает текст. В браузере используется Web Speech API. Если распознавания нет, запись идёт «по таймеру», и упражнение засчитывается по честному слову.

## Отзыв Попугая (гибридный)

1. **Сразу на телефоне** (`analyzeSpeech` в `js/app.js`): число слов, темп, слова-паразиты («ну», «короче», «типа», «как бы», «блин», «значит» и другие из `GOVORUN_FILLERS` в `js/lessons.js`), признаки изученного приёма.
2. **Затем нейросеть** даёт 2–3 предложения живого отзыва: насколько убедительна мысль и сработал ли приём. Порядок такой:
   - `window.claude.complete`, если приложение открыто как артефакт Claude;
   - иначе Cloudflare Worker из папки `worker/`, адрес задан в `js/config.js` → `PARROT_URL`.
3. **Нет сети или Worker не ответил за 12 секунд:** Попугай собирает отзыв из статистики. Под отзывом написано, откуда он: «Отзыв нейросети» или «Отзыв по статистике речи».

### Worker `worker/worker.js`

- Работает на бесплатной нейросети Cloudflare Workers AI (модель `@cf/meta/llama-3.3-70b-instruct-fp8-fast`, запасная `llama-3.1-8b-instruct`). Ключи в приложении не хранятся.
- Промпт собирается на сервере, текст обрезается до 1 500 символов, с одного IP принимается не больше 20 запросов в минуту. Поэтому Worker не получится использовать как бесплатный чат для чего-то другого.
- Бесплатной квоты Workers AI (10 000 «нейронов» в сутки) хватает примерно на несколько сотен отзывов в день. Когда квота кончается, приложение само переходит на отзыв по статистике.
- Опубликован как `govorun-parrot` → https://govorun-parrot.govorun.workers.dev

Обновить Worker (нужен API-токен Cloudflare с правами Workers Scripts: Edit; `ACCOUNT_ID` — номер аккаунта из панели Cloudflare):

```bash
curl -X PUT "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/workers/scripts/govorun-parrot" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  -F 'metadata={"main_module":"worker.js","compatibility_date":"2025-09-01","bindings":[{"type":"ai","name":"AI"}]};type=application/json' \
  -F 'worker.js=@worker/worker.js;type=application/javascript+module'
```

## Файлы

| Файл | Что внутри |
|---|---|
| `js/lessons.js` | Кейсы, темы лифтовых презентаций, слова для импровизации, слова-паразиты, шаги конструктора |
| `js/app.js` | Вся логика: вкладки, урок, тренажёр, конструктор, профиль, анализ речи, отзыв Попугая, сохранение |
| `js/speech.js` | Распознавание речи (Android / браузер) и вибрация |
| `js/fx.js` | Звуки (Web Audio) и конфетти |
| `js/config.js` | Адрес Worker и тайм-аут |
| `style.css` | Стиль Duolingo; шрифт Nunito (SIL OFL) лежит в `fonts/`, интернет для него не нужен |
| `worker/worker.js` | Cloudflare Worker «Попугай-ритор» |

Как добавить кейс: скопировать объект урока в `GOVORUN_MODULES` (`js/lessons.js`) и заполнить `story`, `xray`, `anti`, `quiz`, `builder`, `voice`.

## Сборка

```bash
cd govorun
npm ci
npm run sync          # копирует веб-часть в www/ и в Android-проект
npm run apk           # отладочный APK (нужен Android SDK) → android/app/build/outputs/apk/debug/
```

Проверить в браузере: `python3 -m http.server` в папке `govorun/` и открыть http://localhost:8000 в Chrome. Микрофон в браузере работает только на localhost или по HTTPS.
