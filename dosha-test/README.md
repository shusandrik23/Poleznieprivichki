# Моя доша — тест на определение доши (Android)

Отдельное нативное Android-приложение (Kotlin + Jetpack Compose).

## Что умеет

- Перед тестом спрашивает **имя и возраст**.
- **35 вопросов**, к каждому **6 вариантов ответа**: три «чистых» (Вата, Питта, Капха) и три смешанных (Вата+Питта, Питта+Капха, Вата+Капха) — так легче найти точно подходящий. Порядок вариантов перемешивается.
- **До 12 лет включительно — детская версия**: свои 35 вопросов на «ты», про игры, еду, сон, садик и школу; результат и советы тоже написаны для ребёнка.
- **Результат**: проценты каждой доши, тип (одна доша, двойной тип, если разница ≤ 10%, или сбалансированный, если все три в пределах 8%), описание, сильные стороны, признаки дисбаланса и рекомендации (питание, режим, движение, уход, эмоции), совет по сезонам для смешанных типов.
- Кнопка **«Поделиться результатом»** — текст с типом, процентами и главными советами в любой мессенджер.
- Можно вернуться к предыдущему вопросу и изменить ответ.

## Где что лежит

- `app/src/main/java/com/moyadosha/app/data/AdultQuestions.kt` — вопросы для взрослых
- `.../data/KidQuestions.kt` — вопросы для детей
- `.../data/Recommendations.kt` — описания типов и рекомендации
- `.../data/Scoring.kt` — подсчёт (каждый ответ = 2 балла одной доше или по 1 двум)
- `.../ui/Screens.kt` — экраны

## Сборка

APK собирается автоматически в GitHub Actions при изменениях в `dosha-test/`:
вкладка **Actions → Dosha test APK → Artifacts → moya-dosha-debug**.

Локально: открыть папку `dosha-test` в Android Studio или выполнить `./gradlew assembleDebug`.
