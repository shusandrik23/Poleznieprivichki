# Моя доша / My Dosha — тест на определение доши (Android)

Нативное Android-приложение (Kotlin + Jetpack Compose).

## Что умеет

- Перед тестом спрашивает **имя и возраст** и предлагает выбрать **20, 35 или 50 вопросов**.
- К каждому вопросу **6 вариантов ответа**: три «чистых» (Вата, Питта, Капха) и три смешанных (Вата+Питта, Питта+Капха, Вата+Капха). Порядок вариантов перемешивается.
- **До 12 лет включительно — детская версия**: свои 50 вопросов на «ты», про игры, еду, сон, садик и школу; результат и советы тоже для ребёнка.
- **Язык — по языку телефона**: русский, если система на русском; английский для всех остальных.
- **Результат**: проценты каждой доши, тип (одна доша; двойной тип, если разница первой и второй ≤ 10%; сбалансированный, если все три в пределах 8%), описание, сильные стороны, признаки дисбаланса, рекомендации (питание, режим, движение, уход, эмоции), совет по сезонам для смешанных типов.
- Кнопка **«Поделиться результатом»** — текст с типом, процентами и главными советами.

## Подсчёт

Каждый ответ даёт 2 балла: «чистый» вариант — 2 балла одной доше, смешанный — по 1 двум.
Проценты = баллы доши / все баллы × 100 (с округлением до суммы 100).

Короткий тест (20) — ключевые вопросы (`ADULT_CORE_20` / `KID_CORE_20` в `Model.kt`), 35 — первые 35 вопросов списка, 50 — все.

## Где что лежит (`app/src/main/java/com/moyadosha/app/`)

- `data/AdultQuestions.kt`, `data/AdultQuestionsEn.kt` — вопросы для взрослых (RU / EN, одинаковый порядок и баллы)
- `data/KidQuestions.kt`, `data/KidQuestionsEn.kt` — вопросы для детей
- `data/RecommendationsRu.kt`, `data/RecommendationsEn.kt` — описания типов и рекомендации
- `data/Strings.kt` — надписи интерфейса
- `data/Model.kt` — язык, наборы 20/35/50; `data/Scoring.kt` — подсчёт
- `ui/Screens.kt` — экраны

## Сборка

APK собирается в GitHub Actions при каждом push: **Actions → Android APK → Artifacts → my-dosha-debug**.
Локально: открыть папку в Android Studio или `./gradlew assembleDebug`.
